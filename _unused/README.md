# Архив неиспользуемых файлов

Ничего из этой папки **не подключено к игре**. Она не входит в дистрибутив
(см. `build.sh` — папка исключается из сборки), но файлы сохранены на случай,
если понадобятся later.

Проверено скриптом-ревизией: сопоставлены все файлы `assets/` со всеми
ссылками в `js/*.js` и `index.html`, включая динамические склейки путей
(`'assets/sfx/' + name + '.mp3'` и т.п.).

## sprites/ — старые спрайты щупалец (385 КБ)

`tentacle_body.png`, `tentacle_head.png`, `tentacle_l1..l6.png`

Legacy-версия из ранней реализации щупалец. Актуальные спрайты лежат в
`assets/sprites/tentacle/` (`head`, `body`, `bend_left`, `bend_right`,
`segment`) — именно они используются в `renderer.js`.

## backgrounds/ — неиспользуемые фоны (1.5 МБ)

- `bg_crater2.png` — второй вариант фона кратера, в коде не подключён
  (используется только `assets/bg_crater.png`)
- `title_screen_original.png` — исходный PNG титульного экрана. Игра грузит
  сжатую версию `assets/ui_designs/title_screen.webp`

## audio_original_wav/ — исходные несжатые звуки (3.3 МБ)

Оригиналы в WAV до перевода в MP3. В игре используются `assets/sfx/*.mp3`
(96 kbps): 2.6 МБ → 253 КБ без заметной потери качества для коротких эффектов.

Держим оригиналы здесь, потому что перекодировать заново из MP3 нельзя —
качество деградирует. Если понадобится другой битрейт, исходник брать отсюда.

## audio_original_music/ — исходная музыка (9.3 МБ)

Оригиналы фоновых треков в 185 kbps. В игре — те же треки в 72 kbps
(3.2 МБ), для эмбиент-фона разница на слух не различима.

Причина сжатия: лимит Яндекс Игр — 10 МБ на сборку, а исходный размер
проекта был 16 МБ.
