# Английские версии экранов

Экраны для языка `en`. Русские лежат уровнем выше, в `assets/ui_designs/`,
и считаются базовыми.

## Как это работает

Код грузит экран из папки языка, а если файла там нет — молча берёт русский.
Поэтому набор можно пополнять по одному файлу: переведённые экраны покажутся
на английском, остальные останутся русскими и ничего не сломается.

## Готовность набора

- [x] `title_screen.webp`
- [ ] `pause_screen.webp`
- [ ] `settings_screen.webp`
- [ ] `briefing_screen.webp`
- [ ] `records_screen.webp`
- [ ] `game_over_screen.webp`

`pause_button.webp` переводить не нужно — на нём только значок.

## Важно

**Язык `en` намеренно НЕ включён в `SUPPORTED` в `js/i18n.js`.** Пока набор
неполный, игрок с английским языком увидел бы смесь двух языков — это хуже,
чем последовательный русский. Включать `en` в `SUPPORTED` только когда все
шесть файлов будут на месте.

Проверить внешний вид до этого можно параметром `?lang=en` в адресе — работает
только на localhost и github.io, на площадке Яндекса отключено.

## Требования к файлам

- PNG или WebP, ровно 480 × 854 (можно крупнее с пропорцией 9:16 — уменьшу)
- Геометрия кнопок должна совпадать с русской версией: зоны нажатия
  откалиброваны один раз и используются для обоих языков
- Слоты под значения (статистика на экранах рекордов и поражения) остаются
  пустыми — цифры рисует код
- Внутри дорожек переключателей в настройках ничего не рисовать — кружок
  двигает код
